## OpenJDK

### Install

[Installing Java :: Fedora Docs](https://docs.fedoraproject.org/en-US/quick-docs/installing-java/)

```bash
dnf install java-latest-openjdk{,-devel}
```

Switch versions:

```bash
sudo alternatives --config java
```

Alternatively install the Temurin OpenJDK packages:

[Install Eclipse Temurin™ \| Adoptium](https://adoptium.net/en-GB/installation)
