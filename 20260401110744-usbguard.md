# USBGuard

Installing USBGuard:

```bash
dnf install usbguard             # Install USBGuard
dnf install usbutils udisks2     # Install optional supporting packages
systemctl enable --now usbguard  # Start and enable the usbguard service
```

USBGuard CLI:

```bash
usbguard list-devices            # List devices USBGuard recognizes
usbguard list-devices --blocked  # List blocked USB devices
usbguard list-rules              # List rule sets that USBGuard is using
usbguard remove-rule 3           # Remove rule by number
usbguard allow-device 1          # Allow a USB device by device number
usbguard block-device 2          # Block a device by device number
usbguard reject-device 2         # Disallow and remove a USB device
usbguard allow-device -p 1       # Persistently allow a USB device by device number
usbguard block-device -p 2       # Persistently block a device by device number
usbguard reject-device -p 2      # Persistently disallow and remove a USB device
systemctl restart usbguard       # Reload USBGuard rules
usbguard generate-policy > /etc/usbguard/rules.conf  # Generate policy that allows currently connected USB devices
lsusb             # List attached USB devices
udisksctl status  # List high-level info for disks and block devices
```

* Persistent USBGuard rules are stored in `/etc/usbguard/rules.conf`
* Default USBGuard system config file: `/etc/usbguard/usbguard-daemon.conf`
