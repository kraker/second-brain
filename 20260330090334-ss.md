# ss

```bash
[vagrant@rhel9a ~]$ whatis ss
ss (8)               - another utility to investigate sockets
```

```bash
ss -tlw  # Display TCP sockets, listening sockets, and raw sockets
```

_Raw_ sockets receive packets of a type that the kernel does not explicitly support.
