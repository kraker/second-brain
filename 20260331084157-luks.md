# LUKS

```bash
cryptsetup luksFormat /dev/vdb1           # Encrypt a device/partition
cryptsetup luksDump /dev/vdb1             # Dump LUKS info from a device
cryptsetup open /dev/vdb1 vdb1_encrypted  # Open an encrypted device as a logical-device mapper device
cryptsetup status vdb1_encrypted          # Show status of encrypted block device
cryptsetup close vdb1_encrypted           #
```
