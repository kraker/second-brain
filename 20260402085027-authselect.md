# authselect

```bash
i❯ whatis authselect
authselect (8)       - select system identity and authentication sources.
```

```bash
authselect current                                       # Show current profile
authselect list                                          # List available profiles
authselect list-features <profile>                       # List available features in a profile
authselect show <profile>                                # Show documentation for a profile
authselect select <profile>                              # Select a security profile
authselect select minimal with-pwhistory with-mkhomedir  # Select the minimal security profile with additional features
```
