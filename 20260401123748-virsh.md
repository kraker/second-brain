# virsh

```bash
[root@rhel9a ~]# whatis virsh
virsh (1)            - management user interface
```

virsh CLI:

```bash
virsh list --all     # List all VM's
virsh domstate <vm>  # List state of VM
virsh start <vm>     # Start a VM
virsh console <vm>   # Connect to console of VM
virsh attach-device <vm> path/to/device.xml  # Attach device to VM defined in xml file
virsh detach-device <vm> path/to/device.xml  # Attach device to VM defined in xml file
```

Installation:

```bash
dnf install libvirt-client
```
