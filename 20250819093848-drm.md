#### March 2026 update

Older versions of Kindle for PC (K4PC) no longer connect to amazon. Currently only >= 2.8.3 K4PC versions work to connect. Or if they do, wasn't able to get any versions prior to the latest 2.8.3 to connect for me.
Because of this, the latest crack needs to be used. See method:

[Convert Kindle Books to DRM Free KFX-ZIP ePub PDF without DeDRM Plugin](https://www.epubor.com/kindle-kfx-key-extractor-download-and-how-to-extract-key-from-kindle-kfx.html)

I tested this on Windows Server 2019 & 2022, but this only worked for me on Windows Desktop 11. I was running a VM in VirtualBox on my Fedora machine, a "vagrant box" type VM.

For me the Kindle installer installed globally to C:\Program Files (x86)\Amazon\Kindle, so that's where I needed to copy the KFXArchiver283.exe file to. I wasn't able to find a way to force the installer to install locally to the C:\Users\vagrant\AppData\Amazon\Kindle type path.

And make sure to run cmd _not_ as Administrator.

Note that the latest cracks are in the 2nd fork of the original project which are by Satsuoni: [GitHub - Satsuoni/DeDRM\_tools: DeDRM tools for ebooks · GitHub](https://github.com/Satsuoni/DeDRM_tools). As of this writing it's the v10.0.18 "Pre-release" that contains the needed KFXArchiver283.exe to crack the DRM for K4PC v2.8.3.
The discussion forum is probably the best source of information on getting this working: [Satsuoni/DeDRM\_tools · Discussions · GitHub](https://github.com/Satsuoni/DeDRM_tools/discussions)
